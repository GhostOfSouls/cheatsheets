# Cheatsheets

## MH3220 Algebra II (rings, Ch 1–6)

- [Finals reference sheet (PDF)](MH3220-algebra-II/MH3220-finals-reference-sheet.pdf): 2 pages, fits one double-sided A4 sheet.
  - Side 1: definitions to state, and tests for checking a property (ring, subring, ideal, homomorphism, unit, prime/maximal, irreducibility, ED/PID/UFD, Noetherian/Artinian).
  - Side 2: methods with worked examples (Eisenstein, Gauss's lemma, first isomorphism theorem, CRT, norm arguments, localisation, nilpotents), model answers, standard rings, and a counterexample table for true/false questions.
- [HTML source](MH3220-algebra-II/MH3220-finals-reference-sheet.html): print at 100% scale, double-sided.
