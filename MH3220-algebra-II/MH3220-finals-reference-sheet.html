MH3220 Algebra II · Finals reference sheet (Ch 1–6)

Three parts: definitions to state word for word, tests to check a property, methods to run. All rings commutative with 1 unless said. Red = trap.

1 · Definitions to state

Rings and elements

Ring
A set R with + and · such that (R,+) is an abelian group, · is associative, and both distributive laws hold: a(b+c) = ab+ac, (a+b)c = ac+bc.
Unital / commutative
There is 1 ∈ R with 1a = a1 = a for all a / ab = ba for all a, b.
Zero divisor
a ≠ 0 such that ab = 0 for some b ≠ 0.
Unit
a with ab = ba = 1 for some b ∈ R. Units form the group R×.
Nilpotent / idempotent
xn = 0 for some n ≥ 1 / e2 = e.
Integral domain (ID)
Commutative, unital, 1 ≠ 0, no zero divisors.
Field
Commutative, unital, 1 ≠ 0, every nonzero element is a unit.
Characteristic
Least n ≥ 1 with n·1 = 0; 0 if none exists.
Subring
Non-empty S ⊆ R closed under subtraction and multiplication.
Ring homomorphism
φ(a+b) = φ(a)+φ(b), φ(ab) = φ(a)φ(b) (unital: also φ(1) = 1). ker φ = {a : φ(a) = 0}.

Ideals and quotients

Ideal
An additive subgroup I ⊆ R with rx ∈ I and xr ∈ I for all r ∈ R, x ∈ I.
Principal ideal
(a) = {ra : r ∈ R}. Ideal generated by a1,…,an: {r1a1+⋯+rnan}.
Quotient ring R/I
Cosets a+I with (a+I)+(b+I) = (a+b)+I and (a+I)(b+I) = ab+I.
Maximal ideal
I ≠ R such that I ⊆ J ⊆ R, J an ideal, implies J = I or J = R.
Prime ideal
I ≠ R such that ab ∈ I implies a ∈ I or b ∈ I.
Coprime ideals
I + J = R, i.e. x + y = 1 for some x ∈ I, y ∈ J.

Fractions / localisation

Multiplicative set S
1 ∈ S, 0 ∉ S, S has no zero divisors, s, t ∈ S ⇒ st ∈ S.
Ring of fractions S−1R
Pairs r/s (r ∈ R, s ∈ S) with r/s = r′/s′ ⟺ rs′ = r′s; r/s + t/u = (ru+ts)/su, (r/s)(t/u) = rt/su.
Field of fractions
S = R∖{0} for an ID R.
Localisation R𝔭
S−1R with S = R∖𝔭, 𝔭 prime.
Local ring
Has exactly one maximal ideal.

Factorisation (Ch 4–5)

Associates
a = ub with u a unit.
Irreducible
x ≠ 0, not a unit, and x = ab ⇒ a or b is a unit.
Prime element
x ≠ 0, not a unit, and x | ab ⇒ x | a or x | b.
Euclidean domain (ED)
An ID with ν: R∖{0} → ℤ≥0 such that for a, b ≠ 0 there are q, r with a = qb + r, r = 0 or ν(r) < ν(b).
PID
An ID in which every ideal is principal.
UFD
An ID in which every nonzero non-unit is a product of irreducibles, unique up to order and associates.
Primitive polynomial
f ∈ ℤ[X] whose coefficients have gcd 1.
Content c(f)
gcd of the coefficients; f = c(f)·f0, f0 primitive.

Chain conditions and radicals (Ch 6)

Noetherian
Every ascending chain I1 ⊆ I2 ⊆ ⋯ of ideals stabilises (ACC). ⟺ every ideal is finitely generated ⟺ every non-empty set of ideals has a maximal element.
Artinian
Every descending chain I1 ⊇ I2 ⊇ ⋯ stabilises (DCC).
Krull dimension
sup of n with a chain of primes P0 ⊊ P1 ⊊ ⋯ ⊊ Pn.
Jacobson radical J(R)
Intersection of all maximal ideals. x ∈ J ⟺ 1 − rx is a unit for all r.
Nilradical Nil(R)
The set of nilpotent elements (= intersection of all primes).

Modules (Ch 6)

R-module
Abelian group (V,+) with R × V → V such that (r+s)v = rv+sv, r(v+w) = rv+rw, (rs)v = r(sv), 1v = v.
Submodule
Subgroup W ⊆ V with rw ∈ W for all r ∈ R, w ∈ W. Quotient V/W: r(v+W) = rv+W.
Module hom
Group hom φ with φ(rv) = rφ(v).
Annihilator
Ann(V) = {r ∈ R : rv = 0 ∀v ∈ V}, an ideal.
Finitely generated
V = Rv1 + ⋯ + Rvm for some vi.
Discrete valuation / DVR
ν: F× → ℤ onto, ν(xy) = ν(x)+ν(y), ν(x+y) ≥ min(ν(x), ν(y)). DVR = {x : ν(x) ≥ 0} ∪ {0}. E.g. ℤ(p).

2 · Tests: how to check a property

Is it a ring?

  • (R,+): closed, associative, identity 0, inverses, commutative.
  • · closed and associative.
  • Both distributive laws (check both if · is not obviously commutative).
  • Unital? Find a candidate 1 and check 1·a = a·1 = a. Commutative? check ab = ba.
  • For a new operation like (a,b)∗(c,d): expand both sides of each axiom in coordinates. To disprove, give one explicit triple that fails.

Is S a subring of R?

  • S ≠ ∅ (usually 0 ∈ S).
  • a, b ∈ S ⇒ a − b ∈ S and ab ∈ S.
  • A subring may have no 1 (2ℤ ⊆ ℤ) or a different 1 ({diag(a,0)} ⊆ Mat2).

Is I an ideal?

  • 0 ∈ I; a, b ∈ I ⇒ a − b ∈ I.
  • Absorption: r ∈ R, a ∈ I ⇒ ra ∈ I (and ar ∈ I if not commutative).
  • Shortcut: I = ker φ for a homomorphism ⇒ ideal.
  • Not an ideal: break absorption (ℤ ⊆ ℚ: ½·1 ∉ ℤ) or closure.
  • Contains a unit ⇒ I = R.

Is φ a homomorphism?

  • Check φ(a+b) and φ(ab) (and φ(1) = 1 if unital).
  • Well defined if the domain is a quotient: a + I = a′ + I ⇒ φ(a) = φ(a′).
  • No hom exists: apply φ to a relation. φ(x)2 = φ(x2), φ(1)2 = φ(1), compare.
  • Out of a field: injective or zero.
  • Module action: check the 4 axioms; R/I acts on V only if I ⊆ Ann(V).

Is x a unit / zero divisor?

  • ℤ/n: a unit ⟺ gcd(a,n) = 1; otherwise a ZD (if a ≠ 0).
  • ℤ[√D]: N(a+b√D) = a2 − Db2, multiplicative. x unit ⟺ N(x) = ±1; inverse = conjugate / N(x).
  • R[X], R an ID: units = units of R.
  • x + I unit in R/I ⟺ 1 = rx + i for some r, i ∈ I.
  • ZD: exhibit b ≠ 0 with xb = 0. A unit is never a ZD. Nilpotent ≠ 0 ⇒ ZD.

Is I prime / maximal?

  • Compute R/I (1st isomorphism theorem). R/I ID ⟺ prime. R/I field ⟺ maximal.
  • Not prime: a, b ∉ I with ab ∈ I.
  • Not maximal: an ideal strictly between I and R, or R/I has a nonzero non-unit.
  • In a PID: nonzero prime ⟺ maximal ⟺ (p) with p irreducible.
  • F[X]: (f) maximal ⟺ f irreducible. (X − a) is maximal (F[X]/(X−a) ≅ F).
  • Finite R: prime ⇒ maximal (finite ID is a field).

Irreducible / prime element?

  • Norm: x = ab ⇒ N(a)N(b) = N(x). If no element has norm equal to a proper factor of N(x), x is irreducible. N(x) = ±prime ⇒ irreducible.
  • Not prime: x | ab but x ∤ a, x ∤ b (compare norms).
  • In a PID/UFD prime ⟺ irreducible. Not in ℤ[√−5].

Is f ∈ ℚ[X] irreducible? Run in order

  • 1. Clear denominators, pull out content (Gauss: work in ℤ[X]).
  • 2. deg 2 or 3: irreducible ⟺ no rational root. Roots r/s need r | a0, s | an.
  • 3. Eisenstein at some p; if not, try f(X+1) or f(X−1).
  • 4. Reduce mod p (p ∤ leading coeff): f̄ irreducible in 𝔽p[X] ⇒ f irreducible. Converse false (X4+1).
  • 5. deg 4, no root: write (X2+aX+b)(X2+cX+d) in ℤ[X], compare coefficients, show no solution.
  • Say over which ring: 2X+4 is irreducible in ℚ[X], reducible in ℤ[X].

ID / field / ED / PID / UFD?

  • ID: product of nonzeros is nonzero. Finite ID ⇒ field.
  • Not ID: exhibit ab = 0. R × S is never an ID.
  • Not PID: find a non-principal ideal, e.g. (2, X) ⊆ ℤ[X], (2, 1+√−5) ⊆ ℤ[√−5].
  • Not UFD: two factorisations, 6 = 2·3 = (1+√−5)(1−√−5).
  • R[X] is a PID ⟺ R is a field.

Noetherian / Artinian?

  • Noetherian: PID; finite ring; quotient or localisation of Noetherian; R[X] for R Noetherian (Hilbert). Or show every ideal is f.g.
  • Not Noetherian: strictly increasing chain, (X1) ⊊ (X1,X2) ⊊ ⋯.
  • Artinian: finite rings, fields, F[X]/(f), finite products. Artinian ⇒ Noetherian, dim 0, every prime maximal.
  • Not Artinian: strictly decreasing chain, (2) ⊋ (4) ⊋ (8) ⊋ ⋯ in ℤ.
  • R × S Noetherian (Artinian) ⟺ both are.

3 · Methods (with examples)

Irreducibility over ℚ

  • Rational roots (deg 2, 3): roots r/s need r | a0, s | an; no root ⇒ irreducible. Ex: X3−X−1: f(1) = −1, f(−1) = −1 ⇒ irreducible.
  • Eisenstein at p: p ∤ an, p | ai (i < n), p2 ∤ a0 ⇒ irreducible in ℚ[X]. Ex: 2X5−6X3+9X2−15, p = 3 (3 ∤ 2, 3 | 6, 9, 15, 9 ∤ 15).
  • Shift: f(X) irreducible ⟺ f(X+1) is. Ex: X4+X3+X2+X+1 ↦ X4+5X3+10X2+10X+5, Eisenstein p = 5.
  • Mod p (p ∤ an): f̄ irreducible ⇒ f irreducible. Ex: X3+4X2+3X+7 ≡ X3+X+1 (mod 2); f̄(0) = f̄(1) = 1, no root ⇒ irreducible.
  • Compare coefficients (deg 4, no root): Ex: X4−X2+1 = (X2+aX+b)(X2+cX+d): bd = 1 ⇒ b = d = ±1; c = −a; b+d−a2 = −1 ⇒ a2 = 3 or −1. Impossible ⇒ irreducible.

Gauss's lemma

  • Product of primitive polynomials is primitive.
  • f ∈ ℤ[X] factors in ℚ[X] ⇒ factors in ℤ[X] with the same degrees, so you may compare integer coefficients.
  • Primitive f, deg ≥ 1: irreducible in ℤ[X] ⟺ irreducible in ℚ[X]. Ex: 2X+4 = 2(X+2) is reducible in ℤ[X] (not primitive) but irreducible in ℚ[X].

Identify R/I (1st isomorphism theorem)

  • Build an onto φ: R → S with ker φ = I ⇒ R/I ≅ S. Then: S an ID ⇒ I prime; S a field ⇒ I maximal.
  • Ex: φ: ℤ[X] → ℤ[i], f ↦ f(i). Onto. f(i) = 0: divide by monic X2+1, remainder a+bX with a+bi = 0 ⇒ a = b = 0, so ker = (X2+1). ℤ[i] is an ID, not a field ⇒ (X2+1) prime, not maximal.
  • Ex: ℤ[X]/(2, X2+X+1) ≅ 𝔽2[X]/(X2+X+1), field of 4 elements (no root mod 2) ⇒ maximal.
  • Standard: ℤ[X]/(X) ≅ ℤ · ℤ[X]/(p) ≅ 𝔽p[X] · ℤ[X]/(2,X) ≅ 𝔽2 · ℝ[X]/(X2+1) ≅ ℂ · F[X]/(X−a) ≅ F. Correspondence: ideals of R/I ↔ ideals J ⊇ I.

Homomorphisms and units in R/I

  • No hom: apply φ to a relation. Ex: φ: 2ℤ → 3ℤ, φ(2) = 3k. φ(4) = φ(2)2 = 9k2 and φ(4) = φ(2)+φ(2) = 6k ⇒ k = 0. Ex: unital ℤ[√2] → ℤ[√3]: need (a+b√3)2 = 2 ⇒ 2ab = 0, a2+3b2 = 2, no solution.
  • Unit in R/I: find r with rx ≡ 1. Ex: 1+X in ℤ[X]/(2, X2): (1+X)2 = 1+2X+X2 ≡ 1, self-inverse. Ex: 3−1 = 5 in ℤ/7.

Chinese remainder theorem

I, J coprime ⇒ R/(I∩J) ≅ R/I × R/J, I∩J = IJ. ℤ/mn ≅ ℤ/m × ℤ/n ⟺ gcd(m,n) = 1. Ex: ℤ/12 ≅ ℤ/4 × ℤ/3; ℤ/4 ≇ ℤ/2 × ℤ/2.
Solve x ≡ ai (mod ni): N = ∏ni, Mi = N/ni, yi = Mi−1 mod ni, x = Σ aiMiyi mod N.
Ex: x ≡ 2 (3), 3 (5), 2 (7): M = 35, 21, 15; y = 2, 1, 1; x = 140+63+30 = 233 ≡ 23 (mod 105). Check: 23 = 7·3+2 = 4·5+3 = 3·7+2.

Norm arguments in ℤ[√D]

  • Units: solve a2 − Db2 = ±1. Ex: ℤ[√2]: 1+√2 (N = −1), inverse −1+√2. ℤ[√3]: 2+√3. ℤ[√7]: 8+3√7. D < −1: only ±1.
  • Irreducible: Ex: 2 ∈ ℤ[√−5], N(2) = 4. A proper factor needs norm 2, but a2+5b2 = 2 has no solution.
  • Not prime: Ex: 2 | 6 = (1+√−5)(1−√−5), but 2 ∤ 1±√−5 ((1±√−5)/2 ∉ ℤ[√−5]).
  • Not principal: Ex: (2, 1+√−5) = (d) ⇒ N(d) | 4 and 6 ⇒ N(d) ∈ {1, 2} ⇒ d unit. But all elements a+b√−5 have a ≡ b (mod 2), so 1 ∉ it. Ex: (2, X) ⊆ ℤ[X]: f | 2 ⇒ f = ±1, ±2; ±2 ∤ X; 1 ∉ (2,X) (even constant terms).
  • Euclid in ℤ[i]: Ex: (4+2i)/(3+i) = (14+2i)/10, q = 1, r = 1+i; (3+i)/(1+i) = 2−i exactly ⇒ gcd = 1+i.

Localisation

  • S−1I is an ideal; = S−1R ⟺ I ∩ S ≠ ∅. Every ideal 𝔍 of S−1R is S−1I with I = {r : r/1 ∈ 𝔍} (contraction). Primes ↔ primes P with P ∩ S = ∅.
  • Ex: S = {1, 2, 4, …}: S−1ℤ = ℤ[½]. 6ℤ[½] = 3ℤ[½] (2 is a unit), contracts to 3ℤ. Ideals: nℤ[½], n odd.
  • Ex: ℤ(3) = {m/n : 3 ∤ n}. 5/7 is a unit; 3/5 is not. Ideals 3kℤ(3), 0; unique max ideal 3ℤ(3).
  • Check well-definedness: r/s = r′/s′ ⇒ same output.

Nilpotents, J(R), chains

  • xm = yn = 0 ⇒ (x+y)m+n−1 = 0: each binomial term xiyj (i+j = m+n−1) has i ≥ m or j ≥ n. (rx)m = 0. Needs commutativity.
  • Ex: Nil(ℤ/12) = {0, 6} = (6) = J(ℤ/12) (max ideals (2), (3)). Nil(ℤ/8) = (2). x nilpotent ⇒ 1−x unit, inverse 1+x+⋯+xn−1: (1+2X)2 = 1 in (ℤ/4)[X].
  • Artinian ID ⇒ field: (x) ⊇ (x2) ⊇ ⋯ stops, xn = xn+1y, cancel: 1 = xy. Ex chains: (2) ⊋ (4) ⊋ (8) ⊋ ⋯ ⇒ ℤ not Artinian; (X1) ⊊ (X1,X2) ⊊ ⋯ ⇒ F[X1,X2,…] not Noetherian.

Closing-proof toolkit

  • Every prime maximal: R/P is a field. R finite ⇒ R/P finite ID ⇒ field. Or xn = x ∀x ⇒ x̄(x̄n−1−1) = 0 ⇒ x̄ = 0 or unit. Ex: Boolean ring (x2 = x): R/P ≅ 𝔽2.
  • Exactly one prime: every element unit or nilpotent ⇒ Nil(R) = non-units is maximal and in every prime. Ex: ℤ/pn, F[X]/(Xn).
  • |R| = p2, unital ⇒ commutative: additive order of 1 is p2 (R = ℤ·1) or p (R = ℤ1 + ℤa for any a ∉ ℤ1); generators commute.
  • P prime ⊇ I∩J ⇒ P ⊇ I or J: else a ∈ I∖P, b ∈ J∖P, ab ∈ I∩J ⊆ P.

Key facts

  • Field ⇒ ED ⇒ PID ⇒ UFD ⇒ ID. Maximal ⇒ prime. Prime element ⇒ irreducible (equal in PID/UFD). ID ⇒ char 0 or p.
  • |F[X]/(f)| = |F|deg f. 𝔽4 = 𝔽2[X]/(X2+X+1), 𝔽9 = 𝔽3[X]/(X2+1). R[X] PID ⟺ R field.
  • Nil ⊆ J, equal if Artinian. J(ℤ) = 0, J(ℤ(p)) = pℤ(p). dim: field 0, PID 1, F[X1..Xn] n. Artinian ⇒ Noetherian, dim 0.

Model answers (past-final questions)

  • (X−a) maximal in F[X]: φ: F[X] → F, f ↦ f(a), onto (constants). Division: f = (X−a)q + f(a), so ker φ = (X−a). F[X]/(X−a) ≅ F, a field ⇒ maximal.
  • P = I1∩⋯∩In prime ⇒ P = some Ik: P ⊆ each Ik. If P ≠ Ik for all k, pick ak ∈ Ik∖P; a1⋯an ∈ every Ik, so ∈ P, but P prime gives some ak ∈ P. Contradiction.
  • Subfield has the same 1: 1K2 = 1K ⇒ 1K(1K − 1F) = 0 in the field F, 1K ≠ 0 ⇒ 1K = 1F.
  • New operation on ℝ2: write both sides of associativity and distributivity in coordinates; for a 1, solve (e,f)∗(a,b) = (a,b) for all a, b, then check the other side.
  • Unit is never a ZD: ua = 0 ⇒ a = u−1ua = 0. Finite ID ⇒ field: x ↦ ax injective on a finite set ⇒ onto ⇒ ab = 1.

Standard rings: ideals, primes, units

  • ℤ/n: ideals (d), d | n; maximal = prime = (p), p | n; units: gcd(a,n) = 1, φ(n) of them. J = Nil = (rad n).
  • ℤ[X] primes: 0; (p); (f), f irreducible primitive; (p, f), f̄ irreducible mod p. Only (p, f) are maximal.
  • F[X]: every ideal (f); maximal ⟺ f irreducible; units = nonzero constants. (ℤ/n)[X]: f unit ⟺ a0 unit, ai nilpotent (i ≥ 1).
  • R × S: ideals I × J; primes P × S, R × Q. Units (u, v), u, v units. ZDs (a, 0), (0, b).
  • ℤ[i]: units ±1, ±i; ℤ[i]/(a+bi) ≅ ℤ/(a2+b2) if gcd(a,b) = 1. ℤ[i]/(3) field of 9; ℤ[i]/(2) not an ID ((1+i)2 = 2i). |ℤ[√d]/(n)| = n2.
  • Finite fields: |F| = pn; F× cyclic (generators: 3 in 𝔽7, 2 in 𝔽11).
